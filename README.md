Bienvenue sur le dépôt officiel du portfolio d'**Essia Ajroud**, élève-ingénieure à **ESPRIT** (Tunisie), spécialisée en **Ingénierie des Données (Data Engineering)**, **Intelligence Artificielle** et **Architecture Logicielle**.

## 🌟 Points Forts & Fonctionnalités

- **Interface Orbitale & Réactive** : Navigation fluide avec animations Framer Motion, typographie soignée et design dark néon haute fidélité.
- **Bilingue (Français & Anglais)** : Commutation instantanée de langue avec synthèse vocale intégrée.
- **100 % Autonome (Zero API externe requise)** : Fonctionne de manière entièrement autonome sans nécessiter de clé API externe, d'abonnement ou de backend tiers.
- **Téléchargement direct de CV** : Liens directs et instantanés vers les CV français et anglais.
- **Terminal IA Embarqué** : Assistant interactif intégré capable de répondre à toutes les questions relatives au parcours, compétences, projets et contact.
- **Portail d'Administration Furtif** : Gestion en direct des contenus, photos et documents (accessible en mode sécurisé avec code d'accès maître).

## 🛠️ Stack Technique

- **Frontend** : React 19, TypeScript, Tailwind CSS, Lucide Icons, Framer Motion
- **Visualisation** : Recharts
- **Serveur & API (Optionnel)** : Express Node.js
- **Déploiement** : Prêt pour GitHub Pages, Vercel, Netlify, Render ou Cloud Run

## 🚀 Installation Locale

### 1. Prérequis
- [Node.js](https://nodejs.org/) (version 18 ou supérieure recommandée)
- Git

### 2. Cloner le projet ou extraire l'archive
```bash
git clone https://github.com/<votre-username>/<nom-du-repo>.git
cd <nom-du-repo>
```

### 3. Installer les dépendances
```bash
npm install
```

### 4. Lancer en local
```bash
npm start
```
L'application sera accessible sur `http://localhost:3000`.

### 5. Compiler pour la production
```bash
npm run build
```
Le dossier optimisé prêt pour le déploiement se trouve dans `/build`.

## 🌐 Déploiement

Le projet peut être déployé en 1 clic gratuitement sur :
- **Vercel** : Importez le dépôt GitHub, laissez les réglages par défaut (`Create React App`), et cliquez sur **Deploy**.
- **Netlify** : Glissez le dossier `build` ou connectez votre compte GitHub (Build command: `npm run build`, Publish directory: `build`).
- **GitHub Pages** : Hébergement direct et gratuit depuis les paramètres de votre dépôt GitHub.
